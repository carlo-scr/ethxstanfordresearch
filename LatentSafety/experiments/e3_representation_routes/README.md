# E3 - Specification-aware versus specification-agnostic routes

Test how much compression and performance are traded for one known safety specification versus a
family of held-out specifications. Include a noncompressive/invertible reference when feasible and
learned/noisy safety values as a separate condition.

**Exit gate:** claims clearly state whether they apply to one known `h`, a parameterized family, or
unknown specifications; transfer is measured rather than assumed.
