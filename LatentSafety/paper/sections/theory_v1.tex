\section{Foundations for safe-action sufficiency}\label{sec:theory-v1}

These results provide scoped audit primitives.  Safe/unsafe aliasing, common admissible actions,
and controller refinement are established ideas; submission-level novelty must come from a
validated representation audit and learning intervention, not from the set-theoretic facts alone.
The complete proofs and technical qualifications are in Appendix~\ref{sec:static-proofs}.  All
suprema and infima are extended-real, with
$\sup(\varnothing\cup\{0\})=0$ and $\inf\varnothing=+\infty$.

\subsection{Static soundness and completeness}

Let
\[
 \mathcal C=\{x\in\K:h(x)\geq0\},\qquad
 \mathcal D=\{x\in\K:h(x)<0\},
\]
and let $R:\K\to\Z$ be deterministic.  A latent set $S\subseteq\Z$ is
\emph{sound} if $R^{-1}(S)\subseteq\mathcal C$.  For $m\geq0$, it is closed $m$-complete when
$\{x:h(x)\geq m\}\subseteq R^{-1}(S)$ and open $m$-complete when
$\{x:h(x)>m\}\subseteq R^{-1}(S)$.  Define
\[
 \Gamma_R=\{h(x):h(x)\geq0,\ \exists x'\in\mathcal D\text{ with }R(x')=R(x)\},
 \qquad \epssep(R)=\sup(\Gamma_R\cup\{0\}).
\]

\begin{theorem}[Exact existence equivalence]\label{thm:exact-existence}
Let $m\geq0$ and $S_{\max}=\Z\setminus R(\mathcal D)$.  A latent set $S$ is sound if and only if
$S\subseteq S_{\max}$.  A sound closed $m$-complete set exists exactly when
\begin{equation}
 \Gamma_R\cap[m,+\infty)=\varnothing,\label{eq:closed-completeness}
\end{equation}
whereas a sound open $m$-complete set exists exactly when
\begin{equation}
 \Gamma_R\cap(m,+\infty)=\varnothing.\label{eq:open-completeness}
\end{equation}
Whenever the relevant condition holds, $S_{\max}$ attains it.
\end{theorem}

\begin{proposition}[Infimum completeness threshold]\label{prop:threshold}
Let $\tau_{\geq}(R)$ and $\tau_{>}(R)$ be the infima over $m\geq0$ for which a sound closed or open
$m$-complete set exists, respectively.  Then
\[
 \tau_{\geq}(R)=\tau_{>}(R)=\epssep(R).
\]
For finite $\epssep$, open completeness is attainable at $m=\epssep$; closed completeness is
attainable there if and only if $\epssep\notin\Gamma_R$.  If $\epssep=+\infty$, no finite margin is
attainable.
\end{proposition}

The endpoint distinction is substantive: a safe boundary point with $h=0$ can share a code with an
unsafe point, giving $\epssep=0$ while closed zero-completeness remains impossible.  The maximal
sound-set construction itself is already used by \citet{lutkus2025latent}; the contribution here is
the exact threshold and endpoint accounting, not the collision observation.

\subsection{Exact deterministic post-processing}

\begin{theorem}[Exact deterministic post-processing monotonicity]\label{thm:data-processing}
If $R_2=T\circ R_1$ for deterministic maps $R_1,T$, then
\[
 \Gamma_{R_1}\subseteq\Gamma_{R_2},\qquad
 \epssep(R_1)\leq\epssep(R_2),\qquad
 \tau_{\geq}(R_1)\leq\tau_{\geq}(R_2).
\]
In particular, $\epssep(O)\leq\epssep(E\circ O)$ for a deterministic observation map and encoder.
\end{theorem}

This is an exact-fiber comparison on one input domain.  A raw latent radius has no invariant law:
an injective rescaling preserves fibers while changing neighborhoods.  The result neither
decomposes finite-radius ambiguity nor compares one frame with a richer history.  Finite-radius
observation and privileged-state controls require separately declared geometries.

\subsection{Countable stochastic encoders}

Let $\K$ be countable, let $(\Z,\Sigma)$ be an arbitrary measurable space, and let $P_x$ be the
encoder-output law at $x$.  A measurable $S$ is almost-surely sound when $P_x(S)=0$ for every
$x\in\mathcal D$ and is closed (open) $m$-complete when $P_x(S)=1$ for every $x$ with
$h(x)\geq m$ (respectively $h(x)>m$).  Write $P\perp Q$ for mutual singularity and define
\[
 \Gamma_P^{\rm st}=\{h(x):h(x)\geq0,\ \exists x'\in\mathcal D
 \text{ with }P_x\not\perp P_{x'}\},\qquad
 \varepsilon_{\rm st}(P)=\sup(\Gamma_P^{\rm st}\cup\{0\}).
\]

\begin{theorem}[Almost-sure stochastic separation]\label{thm:stochastic-separation}
An almost-surely sound closed (open) $m$-complete separator exists exactly when
$\Gamma_P^{\rm st}$ avoids $[m,+\infty)$ (respectively $(m,+\infty)$).  Both infimum completeness
thresholds equal $\varepsilon_{\rm st}(P)$, with the same open/closed endpoint distinction as
Proposition~\ref{prop:threshold}.  When $\Sigma$ separates realized codes (as in a standard Borel
space), Dirac laws $P_x=\delta_{R(x)}$ recover the deterministic theory.
If a Markov kernel $K$ post-processes the code laws to $Q_x=P_xK$, then
\[
 \Gamma_P^{\rm st}\subseteq\Gamma_Q^{\rm st},\qquad
 \varepsilon_{\rm st}(P)\leq\varepsilon_{\rm st}(Q).
\]
\end{theorem}

For $\|P-Q\|_{\rm TV}=\sup_{S\in\Sigma}|P(S)-Q(S)|$, the minimum unweighted sum of the two
separator errors is exact and the same overlap also controls randomized latent actions.
\begin{proposition}[Total-variation separation and action tradeoff]
\label{prop:stochastic-tv}
For any safe--unsafe pair $(x,x')$,
\[
 \inf_{S\in\Sigma}\{P_x(S^c)+P_{x'}(S)\}
 =1-\|P_x-P_{x'}\|_{\rm TV}.
\]
If two states have disjoint measurable safe-action sets $A_x,A_y$ and $\pi$ is a randomized latent
policy kernel, let $M_x=P_x\pi$, $M_y=P_y\pi$ and define
$v_x=M_x(A_x^c)$, $v_y=M_y(A_y^c)$.  Then
\[
 v_x+v_y\geq1-\|P_x-P_y\|_{\rm TV}.
\]
Thus, for these disjoint safe-action sets, simultaneous almost-sure action safety requires singular
code laws.  More generally, write $(P,Q)$ for the relevant pair of code laws in either display.
If both have finite KL to a common prior
$\Pi$, Pinsker and the triangle inequality further lower-bound the corresponding error sum by
\[
 \left[1-\sqrt{D_{\rm KL}(P\|\Pi)/2}
          -\sqrt{D_{\rm KL}(Q\|\Pi)/2}\right]_+.
\]
\end{proposition}

Any two nondegenerate Gaussians on $\mathbb R^d$ are mutually absolutely continuous, so no
nontrivial safe--unsafe pair admits exact almost-sure separation under such posterior laws.  This
does not describe our experiments, which audit the deterministic posterior mean rather than
sampled posterior codes.

\subsection{Common actions and finite-action slack}

For a code fiber $F_z^R=\{x:R(x)=z\}$ and declared safe-action sets $\Usafe(x)$, define
\[
 \mathcal A_R(z)=\bigcap_{x\in F_z^R}\Usafe(x).
\]
A fiber is action-conflicted when each member is individually feasible but
$\mathcal A_R(z)=\varnothing$.

\begin{theorem}[Deterministic action conflict]\label{thm:det-action}
A deterministic memoryless decision $\pi(z)$ satisfies the audited condition for every
$x\in F_z^R$ if and only if $\pi(z)\in\mathcal A_R(z)$.  Hence an action-conflicted fiber rules out
every uniformly feasible deterministic memoryless latent decision.
\end{theorem}

For a finite action library and real safety profile $q(x,a)$, let
$\mathcal V_q=\{x:\max_a q(x,a)\geq0\}$ be the individually feasible set and define the exact
worst-fiber common-action violation on viable states
\[
 \beta_{\rm CA}^{\mathcal V_q}(R)=
 \sup_{\substack{z\in R(\K)\\F_z^R\cap\mathcal V_q\neq\varnothing}}
 \left[-\max_a\inf_{x\in F_z^R\cap\mathcal V_q}q(x,a)\right]_+.
\]
\begin{proposition}[Exact common-action data processing]
\label{prop:action-data-processing}
If $R_2=T\circ R_1$ for deterministic maps, then
$\beta_{\rm CA}^{\mathcal V_q}(R_1)\leq\beta_{\rm CA}^{\mathcal V_q}(R_2)$.  Therefore deterministic post-processing of a frozen
code cannot reduce its exact worst-fiber common-action violation, although a non-injective metric
warp may alter a finite-radius audit.
\end{proposition}

Randomization requires care.  Under the stated measurability hypotheses, strong safety means placing probability one on
$\mathcal A_R(z)$; pointwise almost-sure safety only places probability one on each individual
$\Usafe(x)$.  They are equivalent for countable fibers and for compact metric action spaces with
closed safe-action sets, but not for arbitrary uncountable fibers
(Theorem~\ref{thm:rand-action}).  When the common set is nonempty, Euclidean closed-convex action
sets also admit a unique least-intervention projection of a nominal action
(Theorem~\ref{thm:projection}); this is pointwise in $z$ and does not establish a measurable
selector or recursive safety.

For continuous actions, suppose $p\geq1$, $\mathcal U\subset\mathbb R^p$ is nonempty, compact,
and convex, and every $\Usafe(x)$ in a fixed fiber is a nonempty closed-convex subset of
$\mathcal U$.  For nonempty $G$ in that fiber set
\[
 \beta_{\rm geo}(G)=\min_{u\in\mathcal U}\sup_{x\in G}d_2(u,\Usafe(x)).
\]
\begin{theorem}[Helly-compressed convex action audit]\label{thm:helly-action}
For any nonempty, possibly infinite, realized fiber $F_z^R$,
\[
 \beta_{\rm geo}(F_z^R)=
 \sup_{\substack{G\subseteq F_z^R\\1\leq |G|\leq p+1}}\beta_{\rm geo}(G).
\]
The fiber has a common safe action exactly when every at-most-$(p+1)$-state subfiber does.  It is
action-conflicted exactly when $\beta_{\rm geo}(F_z^R)>0$.  For a finite fiber the supremum is a
maximum, so at most $p+1$ states preserve the full geometric slack; the cardinality is sharp.
\end{theorem}

If $q=\dim\operatorname{aff}(\mathcal U)<p$, the same statement holds with the sharper $q+1$
bound after passing to affine coordinates.

This is a fixed-fiber consequence of classical Helly theory.  The norm-relative slack is not a
failure probability or barrier margin, and the result supplies neither a measurable selector
across codes nor recursive safety.  Convexity and compactness are substantive; sampled or
numerically approximate constraints remain finite-reference evidence unless independently
verified.

For $z\in R(\K)$, a finite action set $\{1,\ldots,k\}$, and nonnegative violation loss with
$\sup_{x\in F_z^R}\ell(x,a)<+\infty$ for every action, define
\[
 \beta_{\rm det}(z)=\min_a\sup_{x\in F_z^R}\ell(x,a),\qquad
 \beta_{\rm exp}(z)=\inf_{p\in\Delta_k}\sup_{x\in F_z^R}\sum_{a=1}^kp_a\ell(x,a).
\]
The state is worst-case after $p$ is fixed, but loss is averaged over the sampled action.  In
contrast, the action-wise robust expected and worst-supported-action losses satisfy
\begin{align*}
 \beta_{\rm ar}(z)
 &=\inf_{p\in\Delta_k}\sum_a p_a\sup_{x\in F_z^R}\ell(x,a),\\
 \beta_{\rm ws}(z)
 &=\inf_{p\in\Delta_k}\max_{a:p_a>0}\sup_{x\in F_z^R}\ell(x,a).
\end{align*}

\begin{theorem}[Finite-action pointwise expected-loss slack]\label{thm:finite-action}
For every nonnegative loss,
\begin{equation}
 \frac1k\beta_{\rm det}(z)\leq\beta_{\rm exp}(z)\leq\beta_{\rm det}(z),
 \qquad \beta_{\rm ar}(z)=\beta_{\rm ws}(z)=\beta_{\rm det}(z).
 \label{eq:finite-action-sandwich}
\end{equation}
If $\ell(x,a)=0$ exactly for safe actions and the fiber is action-conflicted, all four slacks are
strictly positive.  For hard failure loss, $\beta_{\rm det}=\beta_{\rm ar}=\beta_{\rm ws}=1$ and
$\beta_{\rm exp}\geq1/k$.  A finite-fiber linear-program dual supplies a traceable adversarial
state mixture; see Appendix~\ref{sec:action-proofs}.
\end{theorem}

\subsection{Average world-model loss does not control a worst fiber}

\begin{proposition}[Smooth localized collision]\label{prop:average-separation}
Fix $a\in(0,1)$, let $X$ be uniform on $[-1,1]$, set $h(x)=x$, and use identity dynamics
$X^+=X$.  For every $0<\delta<\min\{a,1-a\}$ there are smooth scalar encoder, decoder, and latent
predictor with
\[
 \epssep(R_\delta)\geq a,\quad
 \mathbb E|X-D(R_\delta(X))|^2\leq2a^2\delta,\quad
 P(R_\delta(x))=R_\delta(x),\quad
 \mathbb E|X^+-D(P(R_\delta(X)))|^2\leq2a^2\delta.
\]
The same collided fiber is action-conflicted for actions $\{-1,+1\}$ and condition $ux\geq0$.
\end{proposition}

The construction modifies the identity encoder only inside two shrinking smooth bump supports,
while mapping $a$ and $-a$ to the same code.  Thus average reconstruction and decoded prediction
loss vanish even though the worst static and action obstruction stays fixed.  A positive implication
requires tail coverage, uniform regularity, or verification; a small empirical mean is insufficient.

All quantities remain specification-relative: replacing $h$ by $ch$ scales the defect, and encoding
one known scalar margin does not preserve dynamics or common actions.  The static frontier optimizes
over arbitrary latent subsets rather than a neural or verifiable certificate class.  Continuous
nonconvex actions, approximate neighborhoods, uncountable stochastic state families, recursive
feasibility, and long-horizon safety require additional assumptions not supplied here.
